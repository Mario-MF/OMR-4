# OMR Trading & Contracting W.L.L — website

Static bilingual (English / Arabic) site. No build step.

Pages: `/` (index.html), `/about`, `/services`, `/projects`, `/careers`. Images and video: `assets/`.

## Deploy on Vercel
- CLI: `npx vercel --prod` from this folder.
- Or push this folder to GitHub and import it on vercel.com (Framework Preset: **Other**, no build command, output directory `.`).

## Run locally
`npx serve .` then open http://localhost:3000

## One-click deploy
Requires Node.js (https://nodejs.org). Double-click `deploy-windows.bat` (Windows) or `deploy-mac.command` (Mac), sign in to Vercel when the browser opens, and accept the defaults. The live link is printed at the end. Run it again any time to publish updates.
